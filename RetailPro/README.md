# RetailPro

Proyecto de prácticas SQL sobre la base de datos `Ventas_Tech_DB`.

## Orden de ejecución

1. Ejecutar `ventas_tech_db.sql` para crear la base de datos, las tablas y cargar los datos.
2. Ejecutar `m4_consultas_negocio.sql` para obtener las métricas, rankings, comparaciones mensuales y conclusiones.
